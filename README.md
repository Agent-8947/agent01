# DNA Exported Project

## Установка и запуск

1. Распакуйте архив
2. Установите зависимости: `npm install`
3. Запустите dev-сервер: `npm run dev`
4. Для production-сборки: `npm run build`

## Деплой на Vercel

1. Загрузите проект на GitHub
2. Подключите репозиторий к Vercel
3. Vercel автоматически определит настройки Vite

Готово! 🚀
